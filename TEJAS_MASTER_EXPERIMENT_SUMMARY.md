# TEJAS — Master Experiment Summary

## 1. Project Objective

The objective of this experimental study is to develop and evaluate machine learning models for solar power generation prediction using environmental and time-related features.

The study focuses on predicting AC power output from solar plants using weather conditions, irradiation, module temperature, ambient temperature, and time-based features.

The experiments were conducted to:

- Evaluate the performance of machine learning models for solar power prediction.
- Identify the most influential features affecting AC power generation.
- Compare prediction performance across different solar plants.
- Analyze model performance during daytime and nighttime/low-irradiance conditions.
- Investigate the impact of external weather data on prediction performance.
- Study prediction errors using actual-versus-predicted plots and residual analysis.
- Identify limitations and potential improvements for the TEJAS solar prediction system.

### Target Variable

`AC_POWER`

The model predicts the AC power generated by the solar plant.

## 4. Experimental Methodology

### Model

The primary model used in the later experiments was:

**Random Forest Regressor**

### Model Configuration

| Parameter | Value |
|---|---|
| Number of trees | 100 |
| Random state | 42 |
| Parallel jobs | 1 |
| Train-test split | 80% training / 20% testing |
| Splitting method | Chronological |
| Evaluation | Separate evaluation for each plant |

### Chronological Train-Test Split

The data was sorted by timestamp before splitting.

The first 80% of observations were used for training, and the remaining 20% were used for testing.

This approach preserves the temporal order of the data and avoids randomly mixing future observations into the training data.

### Evaluation Metrics

#### Mean Absolute Error (MAE)

MAE measures the average absolute difference between actual and predicted power.

Lower MAE indicates better prediction accuracy.

#### Root Mean Squared Error (RMSE)

RMSE penalizes larger errors more heavily than MAE.

Lower RMSE indicates fewer or smaller large prediction errors.

#### R² Score

R² measures how much of the variation in the target variable is explained by the model.

A higher R² generally indicates a better fit.

## 5. Experimental Investigation

The experiments were conducted progressively to understand the model's performance, the contribution of individual features, the impact of alternative weather data, and the differences between plants.

### Experiments 1–12: Model Baselines and Weather Data Investigation

The early experimental phase investigated baseline model performance and explored the use of alternative weather data, including NASA-derived weather information.

The investigation included:

- Establishing baseline Random Forest performance.
- Comparing the use of original Kaggle weather features with alternative weather inputs.
- Investigating NASA radiation/irradiation data.
- Comparing weather feature distributions.
- Analyzing irradiation differences between data sources.
- Testing radiation scaling and time-alignment approaches.
- Exploring calibration approaches.
- Investigating whether adding external weather features improved predictions.

#### General Findings from the Early Experiments

- The original Kaggle irradiation feature performed better for the tested model configurations than the tested NASA radiation substitutions.
- NASA radiation data showed distribution differences compared with the original irradiation data.
- Simple scaling and time-offset adjustments did not adequately resolve the performance difference.
- NASA-only weather feature models performed worse than models using the original Kaggle weather data.
- Adding NASA radiation as an additional feature did not provide a meaningful improvement in the tested configurations.
- NASA ambient temperature performed similarly to the original ambient-temperature feature in the tested comparison.

## 6. Experiment 13 — Feature Importance Analysis

### Objective

To identify which features contribute most strongly to the Random Forest model's predictions.

### Method

Feature importance was examined using the Random Forest model's impurity-based feature importance values.

### Findings

- IRRADIATION was overwhelmingly the most important feature.
- Time-related features contributed comparatively less.
- Temperature features had smaller contributions compared with irradiation.

The irradiation feature had an approximate impurity importance of 0.9966 in the reported feature-importance experiment.

### Conclusion

Irradiation is the dominant predictive feature in the tested model.

However, impurity-based feature importance should not be interpreted as causal importance. It describes how the model uses features for prediction and does not prove that a feature independently causes changes in power generation.

## 7. Experiment 14 — Permutation Importance

### Objective

To evaluate how model performance changes when the information contained in individual features is disrupted.

### Method

Permutation importance was calculated by measuring the increase in MAE after randomly permuting each feature.

### Baseline Test MAE

234.0495

### Results

| Feature | MAE Increase |
|---|---:|
| IRRADIATION | 7930.067 ± 194.943 |
| hour_sin | 34.9845 ± 7.2282 |
| hour_cos | 27.2826 ± 2.9722 |
| MODULE_TEMPERATURE | 14.9069 ± 2.5139 |
| AMBIENT_TEMPERATURE | -6.2243 ± 1.882 |

### Interpretation

- Irradiation is extremely important for prediction.
- Time features provide meaningful predictive information.
- Module temperature provides a smaller but positive contribution.
- Ambient temperature may be redundant with other information for Plant 1 under this evaluation.

The negative permutation importance for ambient temperature suggests that permuting it slightly improved MAE in this particular test. This does not mean ambient temperature is universally harmful or unnecessary.

### Conclusion

Irradiation is the dominant feature, followed by time-related features and module temperature in the reported permutation-importance experiment.

## 8. Experiment 15 — Feature Ablation Study

### Objective

To determine how removing individual features or groups of features affects model performance.

### Plant

Plant 1 — 4135001

### Method

The same Random Forest configuration and chronological train-test split were used while progressively removing features.

### Results

| Feature Configuration | MAE | RMSE | R² |
|---|---:|---:|---:|
| Baseline — all 5 features | 235.8340 | 516.1849 | 0.9958 |
| Without Ambient Temperature | 236.2746 | 519.5649 | 0.9957 |
| Without Module Temperature | 251.1644 | 546.7376 | 0.9953 |
| Without Both Temperatures | 272.0337 | 575.6489 | 0.9948 |
| Without Time Features | 292.7780 | 589.3389 | 0.9945 |

### Interpretation

- Removing ambient temperature produced only a very small performance change.
- Removing module temperature increased prediction error.
- Removing both temperature features further increased prediction error.
- Removing the time features produced a larger deterioration in performance.

### Conclusion

For Plant 1, ambient temperature appeared to be nearly redundant in the tested configuration, while module temperature and time features contributed more noticeably to predictive performance.

## 9. Experiment 16 — Daytime and Nighttime Ambient Temperature Ablation

### Objective

To examine whether ambient temperature contributes differently during daytime and nighttime/low-irradiance conditions.

### Plant

Plant 1 — 4135001

### Results

| Condition | Samples | Baseline MAE | Baseline RMSE | Baseline R² | Without Ambient MAE | Without Ambient RMSE | Without Ambient R² |
|---|---:|---:|---:|---:|---:|---:|
| Overall | 632 | 235.8340 | 516.1849 | 0.9958 | 236.2746 | 519.5649 | 0.9957 |

### Interpretation

The removal of ambient temperature resulted in only minor changes in performance.

### Conclusion

Ambient temperature had a negligible contribution to Plant 1 performance in the tested model configuration and test period.

This result is specific to Plant 1 and should not be generalized to every solar plant.

## 11. Experiment 18 — Cross-Plant Performance Comparison

### Objective

To compare the performance of the same Random Forest model configuration across both solar plants.

### Method

The same feature set, model configuration, and chronological 80/20 train-test splitting approach were used separately for each plant.

### Results

| Plant | Condition | Samples | MAE | RMSE | R² |
|---|---|---:|---:|---:|---:|
| Plant 1 | Overall | 632 | 235.8340 | 516.1849 | 0.9958 |
| Plant 1 | Daytime | 303 | 484.8134 | 744.5660 | 0.9877 |
| Plant 1 | Nighttime/Low | 329 | 6.5308 | 35.6320 | 0.9824 |
| Plant 2 | Overall | 652 | 717.3942 | 1769.5568 | 0.8971 |
| Plant 2 | Daytime | 317 | 1467.1757 | 2537.6031 | 0.6854 |
| Plant 2 | Nighttime/Low | 335 | 7.8994 | 31.3326 | 0.9882 |

### Interpretation

Plant 1 performed substantially better than Plant 2 overall.

The largest performance difference occurred during daytime generation.

Plant 2 daytime performance was significantly weaker than Plant 1 daytime performance.

### Conclusion

The performance of the same model configuration is plant-dependent.

The results suggest that Plant 2's daytime generation behavior is more difficult to predict using the current feature set and model configuration.

The results do not prove that Plant 2's equipment is defective or that the plant itself is inherently worse.

## 12. Experiment 19 — Actual vs Predicted and Residual Analysis

### Objective

To analyze prediction quality visually and identify error patterns beyond numerical metrics.

### Plant

Plant 1 — 4135001

### Method

The Random Forest model was trained using the same five features and chronological 80/20 split.

Three visualizations were generated:

1. Actual vs Predicted Power
2. Residual Distribution
3. Residual vs Predicted Power

### Residual Definition

Residual = Actual AC Power − Predicted AC Power

- Positive residual: underprediction
- Negative residual: overprediction
- Zero residual: perfect prediction

### Graph 1 — Actual vs Predicted

Observations:

- Most points were close to the ideal diagonal.
- Predictions generally followed actual power values.
- The spread of points increased at higher power levels.
- High-generation predictions showed more noticeable errors.

Conclusion:

The model demonstrates strong overall prediction accuracy, but its prediction consistency decreases at higher power levels.

### Graph 2 — Residual Distribution

Observations:

- Most residuals were concentrated around zero.
- The distribution contained tails on both sides.
- Some large positive and negative errors were present.
- The distribution appeared somewhat asymmetric.

Conclusion:

Most predictions had relatively small errors, but the model occasionally produced larger errors.

### Graph 3 — Residual vs Predicted Power

Observations:

- Residuals were tightly concentrated at low predicted power.
- Error spread increased as predicted power increased.
- Larger residuals were observed at high generation levels.
- Errors occurred on both sides of the zero-residual line.

Conclusion:

The error variance was not constant across prediction levels.

This pattern is commonly described as heteroscedasticity.

The model was generally more consistent at low power levels and less consistent at higher power levels.

Possible reasons for large errors may include rapidly changing weather, variation in irradiation, unusual operating conditions, or information not captured by the current features. The plots alone cannot establish the exact cause.

## 16. Limitations

The experimental study has several limitations.

### Dataset Size and Time Period

The dataset covers approximately one month of observations.

The results may not represent performance across all seasons, weather conditions, or long-term plant operating conditions.

### Plant-Specific Performance

The model performed differently for the two plants.

The results should not be generalized to other solar plants without additional validation.

### Daytime Prediction

Plant 2 demonstrated significantly weaker daytime prediction performance.

Further investigation may be required to understand the differences in generation patterns.

### External Weather Data

NASA-derived weather features were exploratory.

Their timestamps, units, spatial resolution, and correspondence with plant observations were not fully validated in every experimental configuration.

The NASA comparisons should therefore be interpreted as exploratory findings rather than definitive proof that NASA weather data is universally inferior.

### Model Scope

The experiments primarily evaluated Random Forest configurations.

Other algorithms may provide different results and may require further testing before model selection is considered final.

### Error Analysis

Residual plots revealed larger error spread at higher predicted power.

The experiments identified this pattern but did not conclusively establish the physical or operational causes.

### Experimental Scope

The experiments were conducted using historical data.

Real-time performance and long-term reliability require further validation using actual live plant data.

## 17. Overall Conclusion

The experimental study evaluated solar power generation prediction using environmental and time-based features across two solar plants.

The results demonstrated that irradiation was the dominant predictive feature, while module temperature and time-related features provided additional information.

Ambient temperature showed plant-dependent importance. It had little impact on Plant 1 performance when removed but worsened Plant 2 performance when removed. Therefore, it was retained in the shared feature set.

Plant 1 achieved excellent overall prediction performance with an R² of 0.9958, while Plant 2 achieved an overall R² of 0.8971.

The largest performance difference occurred during daytime generation. Plant 1 achieved a daytime R² of 0.9877, while Plant 2 achieved 0.6854.

Both plants achieved excellent nighttime/low-irradiance performance.

Residual analysis showed that most prediction errors were concentrated near zero, but error spread increased at higher power levels. This indicates that although the model performs strongly overall, its prediction consistency is lower at high generation levels.

The tested NASA weather feature configurations did not improve the model compared with the original Kaggle weather features in the evaluated experiments.

Overall, the experiments provided a better understanding of feature contributions, plant-specific performance, generation-condition differences, and model error patterns. The results support retaining the five-feature configuration for continued evaluation while recognizing that additional validation is necessary before making broader operational claims.
